# 香水地圖 Parfum Map

香水地圖＋香水圖書館。依品牌發源地在世界地圖標記香水，可查前中後調、感覺形容詞、外觀圖片，並用搜尋／篩選／相似度找味道相近的香水。

## 預覽
直接雙擊 `index.html` 用瀏覽器開啟即可（需連網才會顯示地圖底圖與字型）。

## 資料夾結構
- `index.html` 頁面
- `css/style.css` 樣式（支援深色模式、手機版）
- `js/app.js` 搜尋篩選、相似度、詳細頁、地圖模組 `MapView`
- `data/perfumes.js` 香水資料（新增香水改這裡）
- `vendor/` Leaflet 地圖函式庫（本機副本）

## 新增一支香水
在 `data/perfumes.js` 的 `PERFUMES` 陣列複製一筆物件修改：
- `city` 對應 `CITIES`（新城市就新增一筆經緯度與洲別）
- `image` 填入香水圖片網址；留空會顯示依香調配色的示意瓶身
- `notes.top / middle / base` 前中後調
- `moods` 感覺形容詞（沿用既有詞彙，篩選才集中）

## 相似度怎麼算
香料重疊（55%）＋感覺重疊（30%）＋同香調家族（15%）。權重在 `js/app.js` 的 `similarity()` 調整。

## 注意
- 前中後調為公開資訊整理的參考值，版本／濃度不同可能有差異，上線前建議再核對。
- 地圖模組已獨立為 `MapView`，之後可替換為 CSSMap 世界大陸地圖。

## 香水圖片
`images/` 內的瓶身圖取自 Fragrantica（fimgs.net），檔名為 `<id>.jpg`，僅供本機對照。網站公開前請換成有授權的圖片（同檔名覆蓋即可）。
